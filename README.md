# File Organizer
 
A simple Python script that cleans up a cluttered folder by moving files into the right place:
 
- **Images** → your `Pictures` folder
- **Documents** → your `Documents` folder
By default it sorts your `Downloads` folder, but you can point it at any folder you like.
 
---
 
---
 
## Example Output
 
```
Sorting: C:\Users\you\Downloads
Moved  resume.pdf        → Documents
Moved  vacation.jpg      → Pictures
Moved  notes.txt         → Documents
Deleted setup.exe        
 
Done: 3 moved, 1 deleted.
```
